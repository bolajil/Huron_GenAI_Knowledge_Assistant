# Acceptable Use Policy (Demo Document)
**Version:** 2026.1 | **Classification:** Internal | **Owner:** Information Technology

---

## 1. Purpose

This Acceptable Use Policy (AUP) defines the permitted and prohibited uses of Huron's information technology resources. It protects the security and integrity of Huron's systems, safeguards client and employee data, and ensures IT resources are used for legitimate business purposes.

All employees, contractors, and authorized users who access Huron IT resources must read and comply with this policy.

---

## 2. Covered Resources

This policy applies to all Huron-provided or Huron-managed IT resources, including:
- Laptops, desktops, and mobile devices (company-issued)
- Network access (office Wi-Fi, VPN, Ethernet)
- Cloud services (Microsoft 365, Azure, SharePoint, Teams, OneDrive)
- Business applications (Workday, Salesforce, ServiceNow, Concur)
- Email accounts ending in @huron.com
- Any system accessed using Huron credentials

---

## 3. Acceptable Uses

Huron IT resources are provided primarily for business purposes. Incidental personal use is permitted within the following limits:

| Activity | Permitted? | Conditions |
|---|---|---|
| Business email and communication | Yes | Primary purpose |
| Personal email (brief, occasional) | Yes | Not from Huron email account |
| Online research for work | Yes | No restrictions |
| Online research for personal interest | Limited | Brief, occasional; not during core hours |
| Streaming music while working | Yes | Via approved apps; no copyright violations |
| Personal file storage on OneDrive | No | Use personal accounts for personal files |
| Banking and financial transactions | Limited | Occasional, brief use |
| Remote access to personal services | No | Cannot configure personal servers on Huron network |

---

## 4. Prohibited Uses

The following uses of Huron IT resources are **strictly prohibited**:

### 4.1 Security Violations
- Attempting to gain unauthorized access to systems, accounts, or data
- Installing software that has not been approved by IT (use the Software Center)
- Disabling or circumventing security software (antivirus, DLP, MDM)
- Sharing passwords or MFA devices
- Using Huron credentials on non-Huron services

### 4.2 Illegal or Harmful Activities
- Downloading, storing, or transmitting illegal content (pirated software, copyright violations, CSAM)
- Harassment, bullying, or discriminatory communications
- Accessing or distributing content that is pornographic, hateful, or violent
- Conducting unauthorized network scanning, penetration testing, or vulnerability research
- Using company resources for personal commercial ventures or outside consulting without written approval

### 4.3 Resource Waste or Misuse
- Mining cryptocurrency on company hardware
- Running personal compute jobs (rendering, AI training) on Huron infrastructure
- Storing personal large media libraries (movies, music, photos) on Huron storage
- Streaming video for personal entertainment during business hours

### 4.4 Data Misuse
- Sending Confidential or Restricted data to personal email accounts
- Uploading client data to non-approved cloud storage (Google Drive, Dropbox, iCloud)
- Accessing records beyond what is required for your role (excess access)
- Retaining client data after an engagement ends without written authorization

---

## 5. Monitoring & Privacy

Huron IT monitors the use of company systems to ensure security, compliance, and appropriate use. By using Huron IT resources, you consent to monitoring.

**What is monitored:**
- Network traffic (URLs visited, data volume, protocol types)
- Email metadata (sender, recipient, subject, size — not content except on legal hold)
- Endpoint security events (DLP alerts, malware detections, login anomalies)
- Privileged account activity (all commands logged for admin accounts)
- Physical access logs (badge swipes)

**What is NOT monitored routinely:**
- Content of personal email accessed via browser on Huron devices (unless suspected policy violation)
- Personal device usage (Huron MDM manages corporate data containers only on BYOD)

Monitoring logs may be disclosed to law enforcement or HR in the course of an investigation.

---

## 6. Software Installation

Only IT-approved software may be installed on Huron-managed devices. To request software:

1. Submit a request via ServiceNow → IT → Software Request
2. Include business justification, vendor information, and license type
3. IT evaluates within 5 business days (security review + compatibility check)
4. Approved software is deployed via Microsoft Endpoint Configuration Manager (MECM)

Prohibited software categories (regardless of business need until reviewed):
- Remote access tools (TeamViewer, AnyDesk) — Huron uses approved remote support tools
- VPN clients other than GlobalProtect
- Cryptocurrency wallets
- Peer-to-peer file sharing applications

## 8. Violations & Consequences

Violations of this policy are handled by HR and IT in coordination with the employee's manager:

| Violation Severity | Examples | Consequences |
|---|---|---|
| Minor | Brief personal use exceeding guidelines, unapproved app installed | Warning, mandatory training |
| Moderate | DLP policy violation, shared password, prohibited software | Written warning, increased monitoring, mandatory re-training |
| Serious | Data breach caused by negligence, illegal content access | Suspension, termination, possible legal action |
| Critical | Intentional data theft, sabotage, criminal activity | Immediate termination, law enforcement referral |

Repeated minor violations escalate to the next severity tier.
